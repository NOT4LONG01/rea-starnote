# 1.0.0-beta.1 on the phone (Galaxy Z Fold 8): the owner's checklist

(For later: 1.0.0-beta.1 is built only after QA bundle 13 comes back with no problems.)

Install `rea-starnote.apk` from the Drive QA folder (it updates the earlier install and keeps its notes: same signing key).
Note PASS / FAIL and a line, or a screenshot, for each; send them to the development session (or paste them in chat).

| # | Check |
|---|---|
| P1 | Both screens: the cover screen (narrow) and the inner screen (nearly square), and folding / unfolding with a note open: the layout adapts, nothing is cut off, no work is lost |
| P2 | Writing: finger, and a pen if you use one on this phone; palm resting on the screen; pinch zoom; how far the ink lags behind |
| P3 | Back button: closes a menu, leaves the editor, goes up a notebook, and only then leaves the app |
| P4 | Notebooks and the Sections view; the page rail in the editor |
| P5 | Export: More menu > *Download .note* and *Export annotated PDF* save through Android's Save-as |
| P6 | **Real StarNote opens our files** (the one check no emulator can do): with StarNote installed, export a QA- note from our app and open it in StarNote: does it open, and is the ink right? |
| P7 | Google Drive sign-in and a sync, and Zotero (only if you want to try them now: they will change with the planned "Sign in with Google" / Zotero "Allow") |
